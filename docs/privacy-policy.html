Unsubmitted Review Alert for GitHub — Privacy Policy

Last updated: 2026-11-13

What the extension does

Unsubmitted Review Alert for GitHub is a Chrome extension that warns you on GitHub pull request pages when you have started a review but have not submitted it.

What data it reads

The extension reads the content of the github.com page you have open, inside your browser, to find out whether that pull request has review comments of yours that are still pending. It does not read any other website.

What it does with that data

The page content it reads (declared in the Chrome Web Store as "Website content") is used only on that page, to show the warning. The extension does not store, transmit, sell or share it. It makes no network requests, has no analytics or tracking, and does not use cookies or extension storage. Everything it reads stays on the page and is discarded when you leave it.

Limited Use

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single purpose, is never transferred to anyone, and is never used for advertising, creditworthiness or lending.
